Task Activity

Every My Tasks assignment across the team — visible only to people granted the "Task Activity" card in the admin panel.
CSV columns: title (required), description, assignee (required — who it's for), priority (high/medium/low), status (not_started/in_progress/blocked/done), due_date, follow_up_date (YYYY-MM-DD), link_url (a link to anywhere — Google Sheet, Smartsheet, source email, etc.). Re-uploading a file downloaded from here updates those same tasks by their id column. New rows with no matching id become new tasks. The language dropdown translates title/description in the exported file (needs translation set up — see the Translate buttons on each task).
